# 13 · 唱游歌簿与音乐

唱游用的歌词歌簿、投影房间,和音乐播放器。

## 歌簿(歌词 + 和弦)

- **管理**:打开 [唱游歌簿](#/crm/songbook) 增改歌词和和弦,也能导入 docx 文件。
- **大家看**:[歌簿列表](https://utba.my/#/music/changyou) 公开可浏览;点一首进阅读器,可调字号、**转调**(和弦自动换算)、写个人改词。

## 唱游房间(投影领唱)

- 打开 [唱游房间](https://utba.my/#/music/changyou-room):**控制端**选歌、翻页、移动高亮行;投影那台电脑开**播放端**,画面实时跟着控制端走。
- 控制端可**生成二维码**,投影设备扫一下就连上。

## 音乐播放器

- 打开 [音乐](https://utba.my/#/music):找歌、播放、排队列、看听歌记录。
- 管理曲库(上传/删除歌曲、专辑封面)需要音乐管理权限。

## 转盘和答题

- [转盘](https://utba.my/#/music/turntable):随机抽人。
- 答题:主持人出题发布,大家在手机上作答,实时统计。
