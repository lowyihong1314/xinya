# 18 · 移动端 / App 发布 / 短信验证 / 信息内容

本篇汇总几个系统级/支撑性功能。

---

## App 发布 / 移动端

**用途**：分发手机 App（APK）；App 端登录与令牌管理。

- **下载 App**：在个人控制台「账户」区下载最新 APK（无需登录即可拉取版本列表）。系统列出所有 `.apk`（含大小、下载链接），按时间新→旧。
- **App 登录**：手机 App 用账密登录，同时获得会话 cookie 与访问/刷新令牌；支持令牌刷新、单端登出、全端登出。登录默认记住 7 天。

**注意**：管理员改「登录版本」可使所有旧会话失效（用于强制全端重新登录）。

---

## 短信验证（OTP）

**用途**：手机号一次性验证码，用于注册、绑定手机、公开付款等敏感/身份场景。

- **发送验证码**：输入手机号，通过短信或语音接收验证码。
- **校验验证码**：输入收到的验证码完成验证。
- 已验证过的手机号在会话内会**短路免验证**。
- **限流**：同一 IP 短时间频繁发送会被限制（提示稍后再试）。

**注意**：需系统预配短信服务凭据。

---

## 信息内容（关于我们 / 历史 / 树洞）

**入口（公开）**：`/info`、`/info/history`。

- **关于我们 / 历史时间线**：公众可浏览；编辑（含配图）需 `edit_info` 权限。
- **树洞留言**：
  - **提交**是公开的（可匿名，正文 ≤ 4000 字）。
  - **查看 / 编辑 / 删除**留言需 `info_tree_hole` 权限。

---

## 小结

| 功能 | 面向 | 权限 |
|---|---|---|
| App 下载 | 所有人 | 无 |
| App 登录/令牌 | App 用户 | 账号密码 |
| 短信验证 | 注册/付款等 | 无（IP 限流） |
| 关于我们/历史 编辑 | 管理员 | `edit_info` |
| 树洞 提交 | 公众 | 无 |
| 树洞 查看/管理 | 管理员 | `info_tree_hole` |
