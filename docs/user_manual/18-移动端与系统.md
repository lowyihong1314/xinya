# 18 · 手机 App 与短信验证

## 手机 App

- 下载:打开 [个人控制台 → 账户](https://utba.my/#/profile/account),点**下载 App**,装最新的 APK(安卓);
- App 用同一套账号密码登录,登录后 7 天免登录;
- 管理员可以强制所有人重新登录(安全需要时)。

## 短信验证(OTP)

公开页(牌位填写、点灯、付款查询等)需要**验证手机号**:

1. 输入马来西亚手机号,点**发送短信验证码**;
2. 收不到短信?点**改用语音电话验证**,接电话听验证码;
3. 输入验证码点**验证并继续**。验证一次管 7 天,期间不用重复验证;
4. 短时间发太多次会被限制,稍等再试。

## 简介页与树洞

- [简介/历史](https://utba.my/#/info/history):公众可看;编辑内容需要相应权限;
- **树洞**:任何人可以匿名留言;查看和管理留言需要权限。
