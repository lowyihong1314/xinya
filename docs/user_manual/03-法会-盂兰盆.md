# 03 · 法会 · 盂兰盆法会（YLP）

盂兰盆法会（YLP）包含**管理工作台**（管理员用）与**公开牌位填写页**（信众自助）。付款审核统一在「财政 · 收款审核」完成（见 [06](06-财务-收款审核.md)）。

**入口**：CRM →「法会」→ YLP 工作区「订单查询」。URL：`/crm/dharma_event?fahui_view=workspace&fahui_workspace=ylp&fahui_section=orders&fahui_ylp_version=2025_YLP`。

**版本**：按年份分版本，命名 `<年>_YLP`（如 `2025_YLP`）。工作台顶部有版本下拉，切换版本会重置分页与多选。

---

## A. 管理工作台 · 订单列表

### 工具条
- **版本下拉**：选择年份版本。
- **搜索框**：按「订单号 / 功德主 / 电话 / 牌位内容」搜索（Enter 或点「搜索」）。
- **分页**：上一页 / 页码 / 下一页；每页 15 条，右侧显示「共 N 条 · X/Y 页」。

### 表格（列：状态、单号、功德主、电话、版本、创建时间）
- **表头排序**：点任一列表头切换升/降序（▲/▼ 指示当前列与方向）。对当前页数据排序。
- **多选**（最左复选框）：
  - 勾选单行；表头复选框「当页全选/取消」（部分选中呈半选态）。
  - 当整页勾选且总数超过本页时，出现横幅「已选中本页 N 条 → **选择全部 X 条记录**」，点击进入**全页全选**；再点「清除选择」退出。
- **点订单行**（非复选框区）进入订单详情。

### 底部批量操作条（有选中时出现）
1. **导出 xlsx**：导出所选订单（列：单号、付款状态、功德主、联络人、电话、版本、创建时间）。文件名 `YLP订单_<版本>_<条数>条.xlsx`。
2. **打印牌位 ▾**（同步，适合少量）：下拉 **大牌位 / 小牌位 / 冤亲债主**，生成后在**新标签打开** PDF。
3. **打印牌位 PLUS ▾**（异步，适合大批量）：同样三选一。启动后台任务 → 弹出进度浮层（进度条 + 百分比，「请勿关闭页面」）→ 完成后**自动下载**已压缩的 PDF。生成大批量时用它，避免长时间等待卡住页面。
4. **取消**：清空选择。

> 牌位打印模板对应：**大牌位 = A 系列（A1/A2/A3）**、**小牌位 = B 系列（B1/B2/B3）**、**冤亲债主 = C**。打印复用系统里既有的牌位定位配置。

### 头部按钮
- **配置支付路径**：维护该版本的收款渠道（见下文 D）。
- **超度亡灵关系配置**：维护填牌位「关系」下拉选项（见下文 E）。
- **打开牌位填写页**：右侧滑出**手机预览抽屉**，内嵌公开填写页 iframe，供管理员预览/测试；有「新标签打开 / 关闭」。

## B. 管理工作台 · 订单详情

**状态控制**（订单状态 `order_status`，默认 Draft）：
- **Draft（草稿）**：可编辑。按钮「**确认 (Confirm)**」「**取消订单 (Cancel)**」。
- **confirm（已确认）**：只读。按钮「**取消确认 (Unconfirm)**→回草稿」「**取消订单 (Cancel)**」。
- **cancel（已取消）**：显示「**重新打开 (Draft)**」；此时才出现「**删除订单**」按钮（**删除前必须先取消**）。
- 取消订单、删除订单均弹确认框。

**顶部操作**：
- **预览牌位**：弹出 PDF 预览浮层（有「新标签打开 / 关闭」）。
- **下载牌位**（移动端走系统分享）。
- **下载报价单**（PDF）。

**订单资料区**（Draft 可编辑，否则标「已确认，只读」）：功德主、联系电话、Email 等；点「保存资料」。

**付款记录区**：列出该订单的付款（方式、金额、状态、时间）。

**项目内容区**（Draft 可「+ 添加项目」，每行可「编辑 / 删除」）：
- 表格显示项目、代码、金额、内容、位置。
- **编辑/添加牌位弹窗**：
  1. 选「牌位类型」（下拉显示 代码·名称·价格）。
  2. 按类型显示字段：**阳上**（多行增删）；**对象 + 关系**（整行一起增删，关系为**下拉**，选项来自「超度亡灵关系配置」）；姓氏、堂号/内容、**显考**、**显妣**、数量。
  3. 底部实时「合计 RM …」，保存即写入订单。
  - 无缘子女（A3/B3）的对象标签显示为「**子女**」，其余为「对象」。

## D. 配置支付路径

**用途**：维护某版本的收款渠道，供公开付款页展示。

1. 列表显示已有渠道（扫码/银行徽章、名称、二维码缩略图或银行信息、备注），可「编辑 / 删除」。
2. 「+ 添加支付方式」，选类型：
   - **扫码支付**：名称（选填）+ **上传收款二维码**（png/jpg/webp/heic）。
   - **银行转账**：银行名称、**银行帐号（必填）**、户名。
   - 备注（选填）。
3. 保存 / 删除（删除弹确认）。

> 校验：扫码类型必须有二维码；银行类型必须填帐号。

## E. 超度亡灵关系配置

**用途**：维护填牌位时「关系」下拉的可选项（先父、先母、后裔、显考、显妣…）。

1. 顶部输入框新增关系（Enter 或「添加」）。
2. 「**从历史数据导入**」：一键从历史订单里出现过的关系批量导入为选项（可再逐个删除整理）。
3. 已有关系以标签展示，点标签上「✕」删除。

> 管理端与公开端的牌位编辑器的「关系」下拉都读取此配置。关闭配置弹窗后会自动刷新选项。

## F. 公开牌位填写页（`/#/ylp-registration`）

信众自助填牌位与付款。步骤条：**验证手机 → 填写牌位 → 确认提交**。

### 步骤 1 · 验证手机
1. 输入马来西亚手机号。
2. 点「继续」：已登录直接放行；未登录走短信/OTP 验证。
3. 按手机号拉取名下订单：有则进「我的资料」，无则直接「全新填写」。

### 步骤 2 · 我的资料（有历史订单时）
- **继续编辑今年**：列出当年**所有可编辑订单**（已付款/审核中会锁定），点其一继续编辑该订单。
- **+ 全新填写一张今年订单**：当年可建多张。
- **我要付款**：进入付款流程（见下）。
- **沿用往年资料**：点往年订单，把内容**复制成今年一张新订单**。
- **← 换个手机号** 返回。

### 步骤 2 · 填写牌位（单屏）
- **功德主资料**：功德主姓名*（必填）、联络人姓名（选填）、电子邮箱（选填）、手机（只读）。
- **牌位清单**：显示小计；每张牌位卡可「编辑 / 删除」；「+ 添加牌位」打开编辑器。
- **牌位编辑器**：选类型 → 阳上（竖排增删，上限 8）→ 亡者/子女+关系（整组增删，关系下拉，上限 6）→ 显考/显妣/数量/附注 → 底部实时金额 →「加入清单 / 保存修改」。
- 「下一步：确认」前校验功德主必填、至少一项牌位。

### 步骤 3 · 确认提交
- 展示汇总。提交时再次验证手机 → 新建或更新订单 → 逐项写入（带「提交中 (done/total)」进度）→ 回「我的资料」提示已保存到订单号。

### 我要付款（多订单合并成一笔）
1. **选择要付款的订单**：可勾选**多张当年订单合并成一次付款**；已付款/审核中不可选（🔒）。底部显示已选张数与合计。
2. **付款方式**：选扫码（显示二维码）或银行转账（显示账号）。
3. **上传付款凭证**（转账截图/收据）。
4. 「提交付款（RM …）」→ 生成**一条覆盖所选订单的付款记录**，回「我的资料」提示等待管理员核对。

> **数据关系：多条订单 → 单条付款记录**。订单支付态：未付款 / 审核中 / 已付款 / 付款失败（失败可重新选择付款）。

## G. 付款如何进入财务

YLP 付款以「法会 YLP」来源出现在 **财政 · 收款审核**（见 [06](06-财务-收款审核.md)）。财务在那里**确认（批准）/ 撤销**收款：
- 确认后所有关联订单变「已付款」；驳回则订单可重新付款。
- 收款审核详情里可点「关联」深链回该 YLP 订单。
- YLP 工作台本身**不再展示付款审核界面**。
