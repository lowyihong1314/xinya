# 03 · 法会 · 盂兰盆(牌位)

信众在公开页自助填牌位、付款;你在工作台看订单、打印牌位。收钱的审核统一在 [收款审核](06-财务-收款审核.md)。

## 打开工作台

点 [法会 → 盂兰盆](#/crm/dharma_event?fahui_view=workspace&fahui_workspace=ylp&fahui_section=orders):

- 顶部**版本下拉**选年份(如 2025);
- **搜索框**可按订单号、功德主、电话、牌位内容找单;
- 点任何一行进入**订单详情**。

## 勾选订单后能做什么

勾选一行或多行(表头复选框全选当页;全选后还会出现「选择全部 N 条」),底部弹出操作条:

- **导出 xlsx**:下载所选订单的名单表格。
- **打印牌位 ▾**:选大牌位/小牌位/冤亲债主,生成 PDF 新标签打开(适合少量)。
- **打印牌位 PLUS ▾**:大批量用这个——后台生成,出现进度条,完成自动下载(等待时别关页面)。
- **创建批量理事会审核 URL** 等其它批量操作视模块出现。

## 订单详情

- 订单默认是**草稿**:可以改功德主资料、**+ 添加项目**加牌位、编辑或删除牌位。
- 点**确认 (Confirm)** 锁定订单;想再改就点**取消确认**回草稿。
- 要删除订单,得先**取消订单**,取消后才出现**删除订单**按钮。
- 顶部还有**预览牌位**(弹 PDF)、**下载报价单**。

**填牌位小抄**:超度历代祖先填「显考/显妣」(先父先母);超度亡灵必须同时填阳上和亡者,关系从下拉选;**冤亲债主只填一位阳上姓名**(牌位内容固定);普度贡品填数量,金额自动算。

## 工作台顶部三个配置按钮

- **配置支付路径**:维护付款页展示的收款方式——扫码(传二维码图)或银行转账(填账号)。
- **超度亡灵关系配置**:维护「关系」下拉的选项,可**从历史数据导入**再删减。
- **开放时间设置**:设定每年几月几号到几月几号开放公开报名(如每年 7/1–9/1)。不在开放期时,公开页会自动提示未开放;如果点灯正开放,还会自动带访客跳过去。
- **打开牌位填写页**:手机样式预览公开页,方便你自己先试一遍。

## 公开填写页(发给信众)

链接:[https://utba.my/#/ylp-registration](https://utba.my/#/ylp-registration)

信众的操作:验证手机号 → 看到自己名下订单(可继续编辑、沿用往年资料、或全新填写)→ 填功德主 + 添加牌位 → 确认提交 → **我要付款**(可勾选多张订单合并付一次,扫码或转账后上传凭证)。

付款提交后,你在 [收款审核](#/crm/finance?account_router=register) 里核对并确认,订单就变「已付款」。
