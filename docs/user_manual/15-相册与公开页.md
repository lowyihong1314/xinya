# 15 · 相册与公开网站

对外的门面:活动照片墙、月历、活动详情。

## 公众看到什么

- [首页](https://utba.my/):月历显示活动,点某天的活动进详情;
- 活动详情页:海报、介绍、活动流程、照片墙、当日签到名单;
- 每张照片有独立链接,可以直接分享某一张。

## 管理照片(需要活动编辑权限)

在活动详情页:

1. 点**上传**,一次选多张照片/视频,进度条跑完自动出现在照片墙;视频会自动转码出缩略图;
2. 勾选多张可**批量删除**;拍歪的照片可**旋转**;
3. 照片墙无限下拉,点图放大预览。

## 编辑活动信息

页面上的活动名称、介绍、海报都来自 [创建活动](02-创建活动.md),在那边改,这边自动更新。
