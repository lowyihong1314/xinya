# 06 · 财务 · 收款审核

**用途**：**跨来源统一收款审核** —— 把以下所有来源的付款汇聚到一处审核：报名表单、会员、青少年佛学班、法会 YLP、法会 Lamp、销售收入。审核 = 核对付款凭证并改状态。

**入口**：CRM →「财务」→「收款审核」→ `/crm/finance?account_router=register`。详情深链带 `&payment_id=<id>`。

**权限**：查看 = `account_read`；改状态 / 替换截图 / 删除 / 写 JE = `account_edit`。

**状态**：处理中 process（默认）/ 已确认 checked / 失败 fail。**确认 = 批准**。

---

## 列表

- 顶部统计：共 N 笔 · 已确认 N 笔 · 已确认金额；「刷新」。
- **两组筛选标签**：
  - 状态：处理中（默认）/ 已确认 / 失败 / 全部。
  - **来源**：全部来源（默认）/ 报名表单 / 会员 / 青少年佛学班 / **法会 YLP** / **法会 Lamp** / 销售收入。
- 搜索框 + 日期区间。
- 勾选多笔后：清空选择、**批量写 JE**、**下载 XLSX**、**导出 Report（PDF）**。
- 列表列：复选框、状态、JE 凭证号、来源、付款人+电话、NRIC、金额、付款方式、关联、提交时间。点行进详情。

## 详情页（左信息 / 右付款截图）

- **左信息栏**：来源、关联、付款人、NRIC、电话、金额、付款方式、柜台、日期、时间、提交时间。
- **状态操作**（需 `account_edit`）：「**处理中 / 已确认 / 失败**」三个切换按钮。
- **仅「报名表单」来源**：处理中状态可「替换/上传付款截图」；失败状态可「移除记录」（二次确认）。其他来源提示「请到对应模块管理截图，这里做收款状态审核」。
- **右栏**：付款截图「查看原图」+ 内嵌预览。
- 头部「查看关联申请」：按来源深链回对应模块（如会员/青少年/法会 YLP 订单/销售）。

## 审核流程

1. 默认看「处理中」待审核记录，点开核对信息与付款截图。
2. 点「**已确认**」通过（会按来源触发下游副作用，如会员/青少年激活、YLP 订单转已付款）；或「**失败**」拒绝；也可改回「处理中」。
3. 报名表单来源截图不清可「替换付款截图」；失败记录可「移除」。
4. 可选「写 JE / 批量写 JE」记账；「下载 XLSX / 导出 Report」。

## 各来源如何进入本页

| 来源 | 如何产生付款 |
|---|---|
| 报名表单 | 公开付款页上传凭证 / 管理员帮成员记录付款 |
| 会员 | 会员申请公开付款页上传凭证 |
| 青少年佛学班 | 青少年班公开付款页上传凭证 |
| 法会 YLP | 牌位填写页「我要付款」（多订单合并一笔） |
| 法会 Lamp | 点灯付款 |
| 销售收入 | 销售单确认后「POST 到收款审核」 |

---

## 注意事项

- 确认（checked）即批准，可能触发下游激活（会员生效、订单转已付款等），操作前请核对清楚。
- 删除仅限「报名表单」来源且状态为失败，不可撤回。
- 会员 / 青少年 / 法会 / 销售的付款**截图**请到各自模块管理，本页只做收款状态审核。
