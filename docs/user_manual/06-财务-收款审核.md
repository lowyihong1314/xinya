# 06 · 财务 · 收款审核

所有进来的钱都汇到这一页审:活动报名费、会员费、青少年班、法会牌位、点灯、销售收入。审核 = 核对付款凭证,点「已确认」。

## 日常审核流程

1. 打开 [收款审核](#/crm/finance?account_router=register),默认显示**处理中**(待审)的付款。
2. 需要的话用**来源**标签筛(报名表单 / 会员 / 青少年佛学班 / 法会 YLP / 法会 Lamp / 销售收入),或搜付款人、选日期。
3. 点一笔进详情:左边是付款人、金额、方式,右边是**付款截图**(点「查看原图」放大核对)。
4. 核对无误点**已确认**;有问题点**失败**;点错了可改回**处理中**。
5. 顶部**查看关联申请**可直接跳到这笔钱对应的订单/申请。

> **点「已确认」= 正式批准**,会自动触发后续:会员生效、订单变已付款等,确认前看仔细。

## 其它操作

- 「报名表单」来源的截图不清楚,可在处理中状态**替换付款截图**;失败的可**移除记录**。
- 勾选多笔后:**下载 XLSX**、**导出 PDF 报表**、**批量写 JE**(记账)。
- 顶部统计条实时显示共几笔、已确认几笔、确认金额合计。
