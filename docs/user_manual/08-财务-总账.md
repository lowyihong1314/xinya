# 08 · 财务 · 总账(做账)

给会计用的复式记账:凭证、现金账、科目表、报表。

## 四个页面

- [会计凭证](#/crm/finance?account_router=gl):记账凭证列表,点行展开借贷明细。点**新建凭证**手工记账:填日期、摘要,逐行选科目填借/贷,页面实时显示是否**借贷平衡**,平了才能**保存并过账**。
- [现金账](#/crm/finance?account_router=gl_cash):点一张资金账户卡(现金/银行),看它的每笔收支流水和余额。只读。
- [科目表](#/crm/finance?account_router=gl_accounts):维护会计科目。要让某科目出现在现金账,编辑时勾**资金账户**并选现金或银行。
- [财务报表](#/crm/finance?account_router=gl_reports):选日期出**试算平衡表**;选科目出**明细账**。

## 平时怎么用(不用手工记账)

大多数凭证不用手工建——在报销、收款审核、销售的单据上点**写 JE**:弹窗已按方向帮你预设借贷科目,确认金额和摘要后点**创建并过账**即可。同一张单不会重复生成;记错了去凭证列表**作废**后重录。

> 过账后的凭证不能改,只能作废重录。
