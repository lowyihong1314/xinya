# 08 · 财务 · 总账 / 现金账 / 科目表 / 报表（GL）

复式记账层，分四个子页：

| 子页 | 入口 |
|---|---|
| 会计凭证 | `/crm/finance?account_router=gl` |
| 现金账 | `?account_router=gl_cash` |
| 科目表 | `?account_router=gl_accounts` |
| 财务报表 | `?account_router=gl_reports` |

**权限**：查看 = `account_read`；所有写操作 = `account_edit`。

**凭证状态**：草稿 draft / 已过账 posted / 已作废 void。

---

## 会计凭证（gl）

- 列表：状态标签（全部 / 已过账 / 草稿 / 已作废）、搜索；列凭证号、日期、摘要、来源、状态、金额；点行展开分录明细。
- **新建凭证**（需 `account_edit`）：
  1. 填凭证日期、摘要（Memo）、参考号（Reference）。
  2. 添加多行分录：科目、借方（Debit）、贷方（Credit）、说明。实时显示借贷合计与「借贷平衡✓ / 差额」。
  3. 至少两条有效分录且借贷相等，才能「**保存并过账**」（直接 posted）。
- 行操作：草稿可「过账」；非作废可「作废」；草稿可「删除」（均二次确认）。

## 现金账（gl_cash，只读）

- 显示资金账户卡片（现金/银行 + 编码 + 名称 + 余额），点选查看该账户流水。
- 流水表：日期、凭证号、摘要、收入(借)、支出(贷)、余额；显示期初/结余。
- 流水**只来自已过账凭证**（由报销、收款的「写 JE」写入）。若无资金账户，提示去科目表勾选「资金账户」。

## 科目表（gl_accounts）

- 类型标签（全部/资产/负债/权益/收入/支出）、搜索。
- **新建 / 编辑 / 删除科目**（需 `account_edit`）：科目编号、名称、类型、期初余额（借方为正）、币种（默认 MYR）、状态（启用/停用）、**资金账户**勾选（计入现金账）→ 勾选后再填资金类型（现金/银行）与银行账号。

## 财务报表（gl_reports，只读）

- **试算平衡**：选日期区间 → 各科目借/贷余额 + 合计 + 「借贷平衡✓ / 不平衡⚠」。
- **明细账**：选科目 + 日期区间 → 该科目分录明细与逐行余额、期初/期末。

---

## 「写 JE」弹窗（报销 / 收款 / 销售复用）

从业务单据点「写 JE」打开：
- 收入方向默认「借现金 / 贷收入」；支出方向默认「借费用 / 贷现金」。
- 填金额/日期/摘要/借贷科目后「**创建并过账**」（按来源单据幂等，不会重复生成）。
- 若该单已生成凭证，会显示凭证号与分录，并提示去总账作废后重录。

---

## 注意事项

- 现金账与报表**只读**，现金流水只来自已过账凭证。
- 凭证过账后不可修改，只能作废重录；作废会幂等回滚源单。
