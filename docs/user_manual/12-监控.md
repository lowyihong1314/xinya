# 12 · 监控(CCTV)

看寺里摄像头的**直播**和**录像回放**,还能遥控镜头转动。

## 直播

打开 [监控](#/crm/cctv),默认就是直播:

- 左上角显示「● 直播中」;连不上会变红,点右上角**重连**;
- **转动镜头**:视频右下角有个摇杆,**按住**方向键镜头就转,松手就停;旁边 **＋/－** 是拉近拉远;
- 也可以直接用**键盘**:方向键转动、`+`/`-` 缩放;
- 点右上角**⤢ 全屏**大画面看,摇杆还在;
- 不动鼠标 3 秒,按钮会自动变淡不挡画面,动一下就回来。

## 回放

点顶部**回放**标签:

- 右边的录像列表按**今天/昨天/日期**分组,每段显示起止时间、时长、大小,点一段就播;
- 一段播完**自动接下一段**;也可点画面下方的**⏮ 上一段 / 下一段 ⏭** 手动切;
- 想保存证据,点右上角**⬇ 下载**存这一段;
- 进度条、暂停等就是普通播放器的用法。

> 看不了这一页?说明你的账号没开通监控权限,找管理员。
