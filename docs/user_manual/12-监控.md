# 12 · 监控（CCTV）

**用途**：观看摄像头直播画面 + 控制云台（PTZ：上下左右、缩放）。

**入口**：CRM →「监控」→ `/crm/cctv`。点按钮打开直播弹窗。

**权限**：依赖 CRM 登录（PTZ 无独立权限门）。

---

## 操作

1. 进入监控页，点按钮打开直播弹窗（HLS 直播画面）。
2. 在弹窗内用方向按钮/缩放按钮**点动控制云台**：
   - 移动/缩放为「点一下动一下」，系统会在短时间后自动停止（防止一直转）。

## 注意事项

- 摄像头连不上时，云台控制会返回错误（503），检查网络与摄像头电源。
- 直播为 HLS 流，需网络通畅。
- 摄像头连接凭据由系统配置，用户无需关心。
