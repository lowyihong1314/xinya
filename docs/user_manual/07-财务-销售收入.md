# 07 · 财务 · 销售收入

卖东西(义卖品、结缘品)走这里:开销售单 → 确认扣库存 → 推给收款审核收钱。

## 开一张销售单

1. 打开 [销售收入](#/crm/finance?account_router=sales_income),点**新建销售**(客户退货则点**销售退回**)。
2. 选仓库、客户、经手人。
3. 逐行选物品和规格(只会列出这个仓库有货的,还显示剩几件)、填数量和单价。
4. 提交后是**草稿**,还没动库存。

## 从草稿到收钱

1. 草稿详情点**确认(扣库存)**——库存这时才真正减掉。
2. 点 **POST 到收款审核**——这单出现在 [收款审核](06-财务-收款审核.md) 等财政确认收款。
3. 卖错了?点**作废(回滚库存)**,货自动补回去。

> 卖货和退货**只走这里**,不要用资产库存里的普通出入库单。库存不够时系统会拦住并告诉你还剩多少。
