# 07 · 财务 · 销售收入

**用途**：基于资产库存的**销售出库 / 销售退回**，走「草稿 → 确认扣库存 → 推送到收款审核收款」。

**入口**：CRM →「财务」→「销售收入」→ `/crm/finance?account_router=sales_income`。

**权限**：建单 / 确认 / 推送 / 作废需 `asset_edit` 或 `account_edit`。

**状态**：草稿 draft / 已确认 confirmed / 已作废 cancelled。推送后收款状态：收款审核中 / 已确认收款 / 收款失败。

---

## 列表

- 只显示销售出库 / 销售退回；有类型标签（全部 / 销售出库 / 销售退回）、搜索。
- 列：单号、类型、状态、客户、仓库、经手、明细、金额、日期。
- 顶部：刷新、**新建销售**（出库）、**销售退回**。

## 新建销售

1. 点「新建销售」（或「销售退回」）。
2. 选仓库、**选择客户**、**选择经手对象**、去向。
3. 逐行选 Item → 规格（销售出库只列当前仓库有库存的规格并显示可用数量）、数量、销售单价、备注。前端会校验库存充足。
4. 提交生成**草稿**。

## 详情页（按状态显示按钮）

- **头部**：单号、类型、状态；若已推送显示收款状态；客户/仓库/经手/金额/时间/备注。
- **明细表**：项目、规格、数量、单价、金额、备注。
- **操作**：
  - `draft`：**确认（扣库存）**、**删除草稿**
  - `confirmed` 未推送：**POST 到收款审核**、**作废（回滚库存）**
  - `confirmed` 已推送：提示「请到财务·收款审核确认收款」+ 作废（回滚库存）
  - `cancelled`：提示「单据已作废」

## 完整流程

1. 新建销售 → **草稿**。
2. 「确认（扣库存）」→ confirmed，扣减库存（退回则回补）。
3. 「**POST 到收款审核**」→ 在 [收款审核](06-财务-收款审核.md) 以「销售收入」来源出现待确认。
4. 财务在收款审核确认收款；如需撤销点「作废（回滚库存）」。

---

## 注意事项

- **销售与退回请走本模块**，不要用资产库存的普通出入库单。
- 库存不足会阻止提交并提示具体规格的可用量。
- 只有确认后才可推送；推送后收款在「收款审核」完成。
- 销售退回 = 客户退货回补库存。
