# 17 · 个人控制台

自己的地盘:改资料、换头像、改密码、会员续费、下载 App。

## 五个分区

打开 [个人控制台](https://utba.my/#/profile/overview),顶部切换分区:

- **概览**:你的身份摘要、最近参加过什么、资料还缺什么;
- **资料**:改姓名、电话、NRIC、病史过敏等,**上传头像**;
- **足迹**:按时间列出你参加过的活动和报名;
- **账户**:**改密码**、**登出**、**下载手机 App**、公司邮件面板(见 [16-公司邮件](16-公司邮件.md)),以及**会员卡片**;
- **银行/转账信息**:填你的银行账号、TNG 号(报销打款用)。

## 会员升级 / 续费

在**账户**分区的会员卡片:

- 还不是会员 → 点**立刻填写注册会员表格**(要先在资料里填好 NRIC);
- 已是会员 → 点**直接续费**,跳出付款页,付款上传凭证即可;
- 提交过申请后,卡片会显示进度:付款审核到哪、理事签了几个名、什么时候到期。
