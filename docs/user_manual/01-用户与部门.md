# 01 · 用户与部门 · 权限管理

**用途**：维护系统用户、部门，以及通过部门分配权限（RBAC）。

**入口**：CRM →「用户与部门」→ `/crm/user_control`。子视图用 `?user_control_view=members|departments` 切换。

---

## 用户管理（成员）

**视图**：`?user_control_view=members`，以名片网格展示，支持搜索、分页（每页 15）。

**操作**：
1. **新建用户**：点「新建」填写用户名、密码、基本资料等。
2. **查看/编辑用户**：点名片进入用户详情页，可改姓名、联系方式、头像等。
3. **重置密码**：管理员为用户重置登录密码（用户忘记密码时用）。
4. **删除用户**：移除账号（二次确认）。
5. **会籍续费记录**：查看/维护会员的续费到期记录。

> 说明：某些账户是「无密码账户」（如青少年班审批通过自动创建的账户），无法登录，需管理员重置密码后才能使用。

---

## 部门管理

**视图**：`?user_control_view=departments`，以部门卡展示，点卡进入部门详情。

**操作**：
1. **新建部门 / 改名 / 删除部门**（需 `department_edit`）。
2. **配置权限**：在部门详情勾选该部门拥有的权限（如 `account_edit`、`form_edit` 等）。
3. **加入成员 / 移出成员**：把用户加进/移出部门；加入成员时用统一的「选择用户」弹窗多选。

---

## 权限如何生效

- 权限是**部门级**的：用户拥有其所属所有部门的权限之并集。
- **要给某人某权限** → 找到（或新建）一个拥有该权限的部门 → 把他加进去。
- 缺权限时，后端会返回「用户 X 没有权限: <权限名>」，前端相应按钮/数据也会隐藏。

### 常用权限一览

| 权限 | 作用 |
|---|---|
| `member_edit` | 编辑用户/会员资料 |
| `department_edit` | 部门增删改、成员进出 |
| `event_edit` | 活动、活动流程、签到、媒体上传 |
| `music_edit` | 音乐/专辑/歌簿增删改 |
| `form_read` / `form_edit` | 报名表格 读 / 编辑 |
| `member_detail` | 查看报名者会员详情 |
| `account_read` / `account_edit` | 财务读 / 确认付款、法会财务、写凭证 |
| `asset_edit` | 资产库存编辑 |
| `youth_class_read` / `youth_class_edit` | 青少年班 读 / 编辑 |
| `council_approve` | 理事会审批 |
| `account_submit_claim` | 提交报销申请 |
| `edit_info` | 编辑关于我们/历史 |
| `info_tree_hole` | 查看/管理树洞留言 |

---

## 注意事项

- 用户名片组件也被公开的信息页复用，编辑用户资料会同时影响后台与公开展示。
- 会员（`is_member`）状态影响续费、青少年班升级等流程，通常由会员/青少年班审批流程自动设置，不建议手动乱改。
