# 01 · 用户与部门

这里管三件事:**人**(账号)、**组**(部门)、**谁能用什么功能**(权限),外加**会员管理**。

## 用户管理

打开 [用户管理](#/crm/user_control?user_control_view=members):

1. 页面是一格格的用户名片,上方有**搜索框**,输入名字或电话就能找人。
2. 点**新建**,填用户名、密码和基本资料,就多了一个账号。
3. **点任何一张名片**进入这个人的资料页,可以:
   - 点字段旁的**铅笔**改资料(姓名、电话、NRIC、病史、过敏等),改完点**保存**;
   - 勾选**会员**开关标记是否正式会员;
   - 在**会员续费历史**里补录续费(选日期、传缴费凭证,点**新增续费**);
   - 点**重置密码**帮忘记密码的人设新密码;
   - 点**删除**移除账号(会再确认一次)。

> 有些账号是青少年班审批后自动创建的,**没有密码**,本人要登录时你先帮他重置密码。

## 部门管理

打开 [部门管理](#/crm/user_control?user_control_view=departments):

1. 点一张部门卡进入详情。
2. 点**新建部门**建组;部门卡上可**改名**或**删除**。
3. 在部门详情点**编辑权限**,勾选这个部门能用的功能,点**保存权限**。
4. 点**加入成员**,在弹窗勾选要加进来的人。

**一句话理解权限**:功能开关挂在部门上,人进了部门就有那个部门的全部功能。想给某人开通某功能 → 把他加进有那个功能的部门。

## 权限管理(按功能看人)

打开 [权限管理](#/crm/user_control?user_control_view=permissions):

1. **左栏**是全部功能开关,每个下面有一行说明(比如 `fahui_read`——查看法会数据),点一个选中。
2. 选中后右边分两栏:**左边是部门**(打勾 = 这个部门有此功能,直接点勾就能给/收),**右边列出目前拥有此功能的所有人**和他们是通过哪个部门拿到的。

## 会员管理

在「用户与部门」菜单下点 [会员管理](#/long_open_registration_form?registration_section=membership),默认打开**会员列表**:

- 全部会员一目了然:姓名、NRIC、账号、有效期、状态(永久/有效/已过期)、缴费次数;
- 上方可按**有效/已过期/永久**筛选,或搜索姓名;
- 其它标签页(申请列表、费率设置、公开报名页)的用法见 [11-长期活动](11-长期活动-会员与青年班.md)。
