# 02 · 创建活动

要办一场活动(法会以外的),从这里开始:建活动 → 配海报和流程 → 关联报名表 → 现场签到。

## 建一场活动

1. 打开 [创建活动](#/crm/event_table),这里列出所有活动,可搜索、按类型筛选。
2. 点**新建活动**,填名称、时间、地点、类型、目的,保存。
3. 点列表里的活动行,进入活动详情。

## 活动详情的四个标签

1. **基本设置**:点字段旁的铅笔改名称、时间、地点、目的等,改完保存。
2. **海报与附件**:点**上传海报**选图(公开相册页和报名页都会用它);还可以上传活动手册和其它附件。
3. **组织者**:点**添加**,勾选负责的同事。
4. **关联报名表**:把活动跟一张报名表格连起来,报名页和活动页会互相跳转(报名表怎么建见 [10-报名表格](10-报名表格.md))。

## 活动流程

在详情里维护当天的环节(几点做什么、谁负责):

- 点**添加**填环节名、时长、详情;
- 按住左侧把手**拖动排序**;
- 环节会自动显示在公开活动页上,标了🔒的环节只有登录用户能看到。

## 财政预算

切到**预算**标签(网址类似 `?event_tab=budget`):

- **收入**:报名收入自动汇总(几人报名、几人付款);也可手动加收入行。
- **支出**:点**+ 新建报销**直接为这个活动提报销;该活动的所有报销自动显示在这里,带审批状态颜色。
- 底部自动算**结余**。
- 点右上角**打印财政报告**,导出一份带活动海报的 PDF 总表(所有收支都列,不分批准与否)。

## 现场签到

- 在活动里生成**签到二维码**,现场让大家扫码;
- 签到名单会显示在活动详情和公开活动页的「当日会员签到」。
