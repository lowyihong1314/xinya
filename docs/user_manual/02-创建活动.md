# 02 · 创建活动

**用途**：维护活动主档（名称、时间、地点、类型）、海报与附件、活动流程、组织者、关联报名表，以及二维码签到。活动数据同时驱动公开的「相册 / 活动详情」页。

**入口**：CRM →「创建活动」→ `/crm/event_table`。`?event_id=` 选中活动、`?event_tab=settings|...` 切换详情标签。

**权限**：查看一般登录即可；新建/删除/编辑、上传海报附件、活动流程、签到等写操作需 `event_edit`。

---

## 活动列表

- 列表列出全部活动，支持「刷新 / 新建活动」、搜索、按类型筛选、分页（每页 15）。
- 点活动行进入详情。

## 新建活动

1. 点「新建活动」，填写活动名称、时间、地点、类型等基本信息。
2. 保存后进入活动详情，继续补充海报、流程、组织者、关联报名表。

## 活动详情（4 个标签）

1. **基本设置**：以「铅笔→保存」的可编辑字段维护活动名称、时间、地点、类型、目的等。
2. **海报与附件**：
   - 上传/更换海报（从媒体库选文件设为海报）。
   - 上传活动手册（brochure）。
   - 上传/删除其他附件。
3. **组织者**：用「选择用户」弹窗添加活动组织者。
4. **关联报名表**：把活动与「报名表格」关联，公开报名/活动详情互相跳转。

## 活动流程（Event Flow）

- 为活动维护多条「流程/环节」，可新建、编辑、删除、**拖拽排序**。
- 流程会显示在活动详情与相册的活动页上。

## 二维码签到（Check-in）

- 生成签到二维码；现场扫码签到；也可手动保存签到、删除签到记录。
- 签到记录随活动一起展示（相册活动页有「当日会员签到」面板）。

---

## 注意事项

- 活动列表数据来自共享数据源，新增/修改后需刷新以同步。
- 海报预览会自动选择合适的图片地址。
- 公开的「相册 / 活动详情」页复用同一套活动与媒体数据，详见 [15-相册与公开页](15-相册与公开页.md)。
