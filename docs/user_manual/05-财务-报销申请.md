# 05 · 财务 · 报销申请

替寺里买了东西想拿回钱?在这里提交报销,财政批准后安排付款。

## 提交一张报销

1. 打开 [报销申请](#/crm/finance?account_router=claim_req),点**新建**。
2. 填金额、日期、部门、用途说明;有收据就上传附件。
3. **偷懒技巧**:上传收据图后点 **AI fillin**,系统自动帮你填金额、日期、商家——记得核对一遍再交。
4. **手写签名**(必填),点**提交**。会得到一个单号,等审批就行。
5. 收据很多张?用**批量 AI 建单**一次传多个文件,一口气生成多张报销单。

## 审批(财政)

点列表里的单进详情:

- 点**批准**(要签名,可留备注)或**拒绝**(必须写原因);
- 左边是申请资料和审批进度,右边是附件预览,可放大、可加/删附件;
- 批准后,审批人点 **Payment Voucher** 生成**收款人签名链接**,复制发给收款人;
- 收款人在手机上签好名后,回来点**下载 Voucher** 得到正式付款凭证 PDF;
- 需要记账的,点**写 JE** 生成会计凭证(见 [08-总账](08-财务-总账.md))。

## 顺手入库

报销买的是物品?详情页点**采购入库**,直接跳到 [资产库存](09-资产库存.md) 并自动带上商家、单号,补个数量就能入库。

## 列表技巧

- 可按状态(已批准/未批准)、日期区间筛选,点表头排序;
- 勾选多张后能**下载 XLSX**、**导出 PDF 报表**、**批量写 JE**。
