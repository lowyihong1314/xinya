# 05 · 财务 · 报销申请

**用途**：内部支出的报销申请、审批流转、付款凭证（Payment Voucher）签名与下载，以及从报销单一键跳转「采购入库」。

**入口**：CRM →「财务」→「报销申请」→ `/crm/finance?account_router=claim_req`。详情深链带 `&claim_id=<id>`。

**权限**：
- 创建报销 = `account_submit_claim`
- 查看全部 = `account_read` 或 `account_edit`（否则只看自己的）
- 审批 / 编辑 / 删除 / 写凭证（写 JE）= `account_edit`

**状态**（由审批人推导）：待处理 pending / 已批准 approved / 已拒绝 rejected。

---

## 列表

- 搜索、状态筛选（全部 / 已批准 / 未批准）、日期区间筛选、可排序列（单号、状态、JE 凭证号、申请人、金额、部门、用途、日期、审批人数）。
- 勾选多行后可：**下载 XLSX**、**导出 Report（PDF）**、**批量写 JE**。
- 顶部按钮：刷新、**新建**、**批量 AI 建单**。

## 新建报销

1. 点「新建」（需 `account_submit_claim`）。
2. 填写：申请人姓名（默认当前用户）、日期（默认今天）、金额、部门、做账分配、用途说明；选填 ref1/ref2、商家名称/地址/联络、采购日期、关联活动、附件。
3. **AI 识别**（可选）：上传收据图片/PDF 后点「AI fillin」自动识别金额/日期/用途/商家等（结果需人工核对，有信心分；可重解析或用 PRO 解析）。
4. **手写签名**（必填）。
5. 校验齐全后点「提交」，回列表并提示单号。

> **批量 AI 建单**：一次上传多个收据文件，批量生成报销单。

## 详情页（左信息 / 右附件）

- **左信息栏**：申请人（可看手写签名）、金额、日期、部门、采购日期、收款人/签收人（可签名）、创建时间、关联活动、用途、AI 说明（ref1/ref2）、商家资料。下方有「审批状态」（每位审批人的批准/拒绝与时间、可看签名）与「修改记录」。
- **右附件栏**：附件计数、多标签切换、图片/PDF 内嵌预览、大图预览、**新增附件 / 删除附件**。

## 头部操作按钮

| 按钮 | 出现条件 |
|---|---|
| 编辑申请 / 保存 / 取消 | `account_edit` 且未锁定 |
| 批准（弹签名，可备注） | `account_edit` |
| 拒绝（必须填原因） | `account_edit` |
| 删除申请（二次确认） | `account_edit` |
| **Payment Voucher** | 当前用户是该单**已批准的审批人** |
| 下载 Voucher | 凭证已被收款人签名后 |
| 写 JE（生成会计凭证） | `account_edit` |
| **采购入库** | 跳转资产库存并预填采购入库单据 |

## 审批与付款凭证流程

1. 详情页点「批准」（必须签名）或「拒绝」（必须填原因）。
2. 审批人点「**Payment Voucher**」→ 弹窗显示**公开签名链接**。
3. 「复制链接 / 打开签名页」发给收款人；收款人在公开页填全名并手写签名。
4. 签名完成后点「下载完整 Voucher」导出含中文内容 + 签名的 PDF。
5. 可选：点「写 JE」生成过账凭证（详见 [08-总账](08-财务-总账.md)）。

## 采购入库联动

- 详情页点「采购入库」→ 跳到资产库存「库存单据」，自动打开采购入库表单并按报销单预填（供应商 = 商家名、备注 = 用途、发票号 = 报销单号）。详见 [09-资产库存](09-资产库存.md)。

---

## 注意事项

- 已锁定（`is_locked`）的报销单不可再编辑附件/活动/内容。
- 拒绝必须填原因、批准必须签名。
- AI 识别结果务必人工核对。
- 未签名不能下载完整 Voucher。
