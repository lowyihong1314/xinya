## 提示「没有权限」怎么办

看到「权限不足」或找不到某个按钮,通常是你的账号没被开通对应功能。**联系管理员**,告诉他你要用哪个功能,他会在 [用户与部门 → 权限管理](#/crm/user_control?user_control_view=permissions) 里把你加进对应的组。
