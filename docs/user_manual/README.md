# 新雅寺庙 CRM 系统 · 用户手册

本手册面向系统的**日常使用者与管理员**，按模块讲解「用途 / 入口 / 操作步骤 / 字段与状态 / 权限 / 注意事项」。技术实现细节不在本手册范围。

## 系统概览

- 登录后台后进入 CRM 工作台：`/crm`（未登录会提示「请先登录后台」并弹出登录框）。
- 左侧为模块导航（ERP Console / CRM 工作台），点击进入各模块。
- 部分模块有**公开页**（无需登录），如报名页、付款页、牌位填写页、相册、树洞等，通过链接对外发布。

## 权限速查

系统采用 **RBAC**：权限挂在「部门」上，用户通过所属部门获得权限。给某人放权 = 把他加进拥有该权限的部门。

| 权限名 | 作用范围 |
|---|---|
| `member_edit` | 编辑用户 / 会员资料 |
| `department_edit` | 部门增删改、成员进出 |
| `event_edit` | 活动增删改、活动流程、签到、媒体上传 |
| `music_edit` | 音乐 / 专辑 / 歌簿增删改 |
| `form_read` / `form_edit` | 报名表格 读 / 编辑 |
| `member_detail` | 查看报名者会员详情 |
| `account_read` / `account_edit` | 财务读 / 确认付款、法会财务、写凭证 |
| `asset_edit` | 资产库存编辑（销售亦认 `account_edit`） |
| `youth_class_read` / `youth_class_edit` | 青少年班 读 / 编辑 |
| `council_approve` | 理事会审批（会员 / 青少年班） |
| `account_submit_claim` | 提交报销申请 |
| `edit_info` | 编辑「关于我们 / 历史」 |
| `info_tree_hole` | 查看 / 管理树洞留言 |

> 组合规则示例：报名表格工作台只需 `form_read`、`form_edit`、`member_detail` 三者其一即可进入。
