# 11 · 长期活动 · 会员与青少年班

**用途**：把「会员升级/续费」与「青少年佛学班」两个长期开放的报名流程放进同一个 CRM 工作台，做审批与付款跟进。两者都走**双审批**：**财政确认付款 + 理事会签名**，都通过后才生效。

**入口**：CRM →「长期活动表格」→ `/crm/long_open_registration_form`。`?registration_section=membership|youth_class` 切换分区（旧的 `membership_registration` / `youth_class_registration` 会自动跳到这里）。

**通用工作台**：条目列表 → 详情 → 付款跟进 → 理事会签名 → 费用设置，两个流程共用同一套界面，只是数据来源不同。

---

## 会员（membership）

**用途**：非会员升级为会员、会员续费。

**公开页**：会员申请 `/template/membership-application`；付款页 `/template/membership-payment?t=<token>`。

**申请流程**：
1. 公开申请页填写：Facebook 主页、住家地址、籍贯、职业、是否皈依、紧急联络人（姓名+电话）、**加入身份**（须在给定选项内）等；皈依=是须填皈依年份与证明法师。
2. 若系统有可选推荐人则必须选一位现有会员。
3. 提交生成申请（状态：处理中），返回付款链接。
4. 公开付款页上传付款凭证。
5. **财政**在管理端确认付款（`account_edit`）；**理事会**在工作台签名（`council_approve`，上限 20 人）。
6. 两方都通过后生效：创建/关联会员账户、设为会员、建立续费到期记录。

**续费**：会员可发起续费流程（同样走付款 + 审批）。

**状态**：处理中 process / 已生效 paid / 已退回 reject。

**权限**：读工作台 = `member` / `member_edit` / `account_edit` / `council_approve` 任一；改字段/费用设置 = 编辑级；确认付款 = `account_edit`；理事会签名 = `council_approve`。

---

## 青少年佛学班（youth class）

**用途**：13–17 岁青少年佛学班报名，双审批生效；生效时自动建**无密码账户**，之后可一键升级为会员申请。

**公开页**：报名 `/template/youth-class-registration`；付款 `/template/youth-class-registration/payment?t=<token>`。

**流程**：
1. 公开报名填中英文名、username、NRIC、住家地址、性别、手机、紧急联络人（姓名+电话+关系）。
2. **资格校验**：按 NRIC 算年龄，**13–17 岁合格**，否则提示不符资格。
3. 生成申请（处理中），返回付款链接。
4. 公开付款页按年龄取费用、上传凭证（已确认者不可重复提交）。
5. 财政审核付款；理事会签名（上限 20）。
6. 两方通过后生效（paid），并按 username 建/关联一个**无密码账户**（无法登录，需管理员重置密码；不建续费）。
7. **升级为会员**：仅已生效且绑定成员可升级，一键创建会员申请（带出资料），再走会员的财政+理事会审批。

**状态**：处理中 process / 已生效 paid / 已退回 reject。

**权限**：读工作台 = `youth_class_read` / `youth_class_edit` / `council_approve` 任一；改费用/状态 = `youth_class_edit`；理事会签名 = `council_approve`；付款审核仍属财政 `account_edit`。

---

## 通用工作台功能

1. **条目列表**：显示各申请（提交时间、姓名、状态：已生效/已退回/处理中）。
2. **详情**：查看/编辑字段。
3. **付款跟进**：看付款凭证、改收款状态（处理中/已确认/失败）。
4. **理事会签名**：显示需签人数/上限/已签/是否可签，支持单签或生成**批量签名链接**。
5. **费用设置**：按年龄段设会费/班费（带图片）。
6. 仅青少年班有「升级为会员」。

---

## 注意事项

- 会员与青少年班的公开报名页共用同一模板，通过参数区分。
- 理事会签名与财政确认是**两道独立关卡**，缺一不生效。
- 青少年班生效创建的账户无法直接登录，需管理员重置密码。
