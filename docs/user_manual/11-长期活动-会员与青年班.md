# 11 · 会员管理与青少年佛学班

两个长期开放的报名:**会员**(入会/续费)和**青少年佛学班**。都要过两关才生效:**财政确认付款 + 理事签名**。

## 会员管理

入口在「用户与部门」菜单下:点 [会员管理](#/long_open_registration_form?registration_section=membership)。

**四个标签页:**

1. **会员列表**(默认):全部会员名册——姓名、NRIC、账号、有效期、状态(永久/有效/已过期)、缴费年数。可筛选可搜索。
2. **申请列表**:待处理的入会/续费申请。点一条进详情:
   - 核对资料(点铅笔可改);
   - **付款记录**区:核对凭证后点**通过**(或退回);
   - **理事会审核**区:进度条显示已签几个(满 5 个过关)。你有签名权就点**我要签名**手写签名;也可点**复制签名 URL** 发给理事在手机上签;
   - 列表页勾选多份申请可**创建批量理事会审核 URL**,理事签一次名覆盖全部。
   - 付款和签名都齐了,申请自动生效:对方成为会员、记录到期日。
3. **费率设置**:按年龄段设会员费,上传收款二维码。
4. **打开公开报名页**:复制报名链接发给申请人,或手机预览。

**公开报名链接**:[https://utbabuddha.com/template/long-open-registration-form](https://utbabuddha.com/template/long-open-registration-form)——对方输入 NRIC,系统按年龄自动分流到会员表或青少年班表;提交后自动跳付款页上传凭证。

## 青少年佛学班

入口:「长期活动」菜单 → [青少年佛学班](#/long_open_registration_form?registration_section=youth_class)。

- 工作台和会员长得一样:申请列表、详情、付款核对、理事签名(**只需 1 个签名**)、费率设置。
- 13–17 岁才能报名,系统按 NRIC 自动把关。
- 生效后系统自动给学员建一个**无密码账号**;学员要登录时管理员先帮他重置密码。
- 学员长大要入会?详情页点**升级为会员**,资料自动带过去生成会员申请,再走会员的两关。

> 提醒:两关缺一不可——只付了钱没签够名、或签够名没确认付款,都不会生效。
