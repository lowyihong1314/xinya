# 14 · 文件系统

**用途**：企业网盘式的文件浏览、上传、目录权限、分享与回收站。

**入口**：CRM →「文件系统」→ `/crm/files`（独立路由 `/files`）。

---

## 操作

1. **浏览 / 搜索**：以目录树浏览文件与文件夹。
2. **上传**：把文件上传到当前目录。
3. **新建 / 改名 / 移动 / 归档 / 删除**：管理文件与目录。
4. **目录权限**：为目录设置权限级别：
   - `read`（只读）
   - `read_write`（读写）
   - `read_public`（公开可读）
5. **分享链接**：为文件生成公开分享链接，对方无需登录即可下载。
6. **回收站**：删除的项目进入回收站，可**还原**。

---

## 注意事项

- 已弃用旧版文件路由，请使用当前的文件系统模块。
- 当前尚未提供的能力（后续完善）：回收站永久删除、分享列表/撤销、复制文件/目录、单文件细粒度权限、独立搜索接口。
