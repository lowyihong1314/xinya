# 14 · 文件系统

寺里的共享网盘:存文件、管权限、发分享链接。

## 日常操作

打开 [文件系统(新版)](#/crm/files_v2):

1. 像网盘一样点文件夹进出;顶部有**全局搜索**;
2. **上传**:点上传按钮,或直接把文件**拖进页面**;
3. 右键/更多菜单:**新建文件夹、改名、移动、删除**;
4. 支持**批量勾选**后一起删除;
5. 点图片/PDF 直接**预览**,不用下载。

## 分享给别人

选中文件点**分享**,生成公开链接,对方**不用登录**就能下载。

## 权限

给文件夹设权限:只读 / 读写 / 公开可读。没权限的人看不到对应目录。

## 回收站

删掉的东西先进**回收站**,可以**还原**;确定不要了再永久删除。
