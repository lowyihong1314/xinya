# 04 · 法会 · 点灯法会（LAMP）

**用途**：管理点灯登记（祈福者、供灯明细、金额、状态）。付款审核统一在「财政 · 收款审核」完成。

**入口**：CRM →「法会」→ LAMP 工作区。点灯与盂兰盆同属「法会」，侧边栏分别是「盂兰盆法会」和「点灯法会」。

**权限**：查看一般登录即可；编辑资料、改状态、删除需 `account_edit`。

---

## 列表页

- 顶部：标题「点灯登记」+「共 N 条」+「刷新」。
- **筛选**：状态标签 **全部 / 草稿 / 已确认 / 已取消** + 搜索框（祈福者 / 电话 / 地址 / 状态）。
- **排序**：点表头排序（状态、祈福者、电话、金额、登记时间；供灯列不排序）。
- **分页**：上一页 / 页码 / 下一页。
- 表格列：状态（彩色标签）、祈福者、电话、金额（RM）、供灯（项数）、登记时间。
- 点行进入详情（`?lamp_id=<id>`）。

## 详情页

**状态控制**（draft / confirm / cancel）：
- **draft（草稿）**：「确认 (Confirm)」。仅草稿可编辑资料。
- **confirm（已确认）**：「取消确认（回草稿）」「取消登记」。
- **cancel（已取消）**：「重新打开（草稿）」。
- 始终有「**删除登记**」（弹确认）。「取消登记」也弹确认。

**登记资料**（draft 可编辑）：登记编号、祈福者、电话、地址、合计、登记时间；点「保存资料」。

**供灯明细**：灯种、金额、备注。

底部提示：「点灯付款审核已移至『财政 · 收款审核』统一管理」。

---

## 付款与财务

- 点灯付款以「**法会 Lamp**」来源汇入 **财政 · 收款审核**（见 [06](06-财务-收款审核.md)），在那里确认/撤销收款。
- 点灯的工作流状态（草稿/确认/取消）与付款状态是**解耦**的：改点灯状态不影响付款，反之亦然。

---

## 注意事项

- 所有破坏性操作（取消登记、删除登记）都走确认对话框。
- 公开点灯登记页（若有）由公开渠道承载；CRM 内的点灯模块主要是**管理端**列表与详情。
