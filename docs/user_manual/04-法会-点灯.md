# 04 · 法会 · 点灯

管理点灯登记:谁点了什么灯、金额多少、确认或取消。

## 打开工作台

点 [法会 → 点灯](#/crm/dharma_event?fahui_view=workspace&fahui_workspace=lamp&fahui_section=orders):

- 顶部标签按状态筛选:**全部 / 草稿 / 已确认 / 已取消**;搜索框可搜祈福者、电话、地址;
- 点**开放时间设置**维护每年的开放时段(如 1/1–2/1、4/1–5/1),不在开放期公开页自动关闭并引导去盂兰盆;
- 点任何一行进入详情。

## 登记详情

- **草稿**状态可以改资料(祈福者、电话、地址),改完点**保存资料**;
- 点**确认 (Confirm)** 定案;确认后还能**取消确认**退回草稿,或**取消登记**;
- **删除登记**随时可点(会再确认一次);
- 下方**供灯明细**列出每盏灯的灯种、金额、备注。

## 收钱在哪里?

点灯的付款不在这页审——去 [收款审核](#/crm/finance?account_router=register),来源筛「法会 Lamp」,核对凭证后点**已确认**。

## 公开登记页(发给信众)

链接:[https://utba.my/#/lamp-registration](https://utba.my/#/lamp-registration)

信众验证手机号后选灯、填资料、提交、上传付款凭证。**只在开放时段可用**;截止期间打开会提示未开放,并自动跳到当时开放的法会。
