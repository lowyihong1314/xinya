# 09 · 资产库存

管仓库和物品:先建档案,再用单据出入库,库存和流水自动算。

## 第一次使用:建档案

打开 [基础档案](#/crm/asset?asset_panel=master),依次建好:

1. **仓库**(名称、位置);
2. **往来对象**(供应商、客户);
3. **Item 和子 Item**——Item 是物品(如「T恤」),子 Item 是具体规格(如「白色 M 码」),库存都记在规格上。

## 出入库:一律开单据

打开 [库存单据](#/crm/asset?asset_panel=documents),点**新建单据**:

1. 选类型:采购入库 / 手动入库 / 内部领用 / 仓库调拨 / 盘点调整(卖货请走 [销售收入](07-财务-销售收入.md));
2. 选仓库、往来对象、经手人;采购入库还能**选择关联报销单**,自动带单号;
3. 逐行选规格、数量、单价,保存成**草稿**;
4. 草稿点**确认**才真正改库存;确认前可编辑、上传发票、删除;
5. 记错了点**作废**,库存自动回滚。

## 查库存

- [库存明细](#/crm/asset?asset_panel=inventory):每个仓库每个规格现在有多少,可搜索、导出 CSV、逐行设**最低库存**;
- [低库存提醒](#/crm/asset?asset_panel=low_stock):跌破最低线的规格都在这;
- [Item 汇总](#/crm/asset?asset_panel=item_summary):按物品看总量,点进去可直接维护该物品和规格;
- [库存流水](#/crm/asset?asset_panel=movements):每一笔进出的历史记录。
