# 09 · 资产库存

**用途**：仓库/物料主数据、库存单据（入库/出库/调拨/调整）、库存明细、低库存提醒、Item 汇总、库存流水。

**入口**：CRM →「资产库存」→ `/crm/asset?asset_panel=<面板>`。面板：`master`（基础档案）/ `documents`（库存单据）/ `inventory`（库存明细）/ `low_stock`（低库存）/ `item_summary`（Item 汇总）/ `movements`（库存流水）。

**权限**：读 = `asset_read` 或 `account_read`；写（增删改/确认/作废/上传/设阈值）= `asset_edit` 或 `account_edit`。

**单据状态**：草稿 draft / 已确认 confirmed / 已作废 cancelled。

---

## 六个面板

### 基础档案（master）
- **仓库**：名称/编码/位置。
- **往来对象**（供应商 / 客户 / 两者）：联系人、电话、地址。
- **Item 与子 Item**：子 Item 是规格（名称/SKU/尺寸/颜色）。
- 每类支持新建/编辑/删除。

### 库存单据（documents）
- 新建/编辑草稿、确认、上传发票、作废、删除。
- **单据类型**：采购入库 / 手动入库 / 内部领用 / 仓库调拨 / 卖出 / 销售退回 / 盘点调整。
  - 提示：**销售与退回请改走「销售收入」模块**（见 [07](07-财务-销售收入.md)）。
  - 仅**采购入库**会显示「选择关联报销单」，并把报销单号写入发票号。

### 库存明细（inventory）
- 按仓库/规格列出可用/保留/最低库存；可搜索、按仓库过滤、导出 CSV、逐行设置最低库存阈值。

### 低库存提醒（low_stock）
- 列出「设了最低库存且当前可用 ≤ 最低」的规格。

### Item 汇总（item_summary，主从结构）
- 以全部 Item 为准合并库存统计（可用/保留/仓库数/子 Item 数/低库存规格数）。
- 点行进入 **Item 详情**，在详情页内直接维护该 Item 与其子 Item（新建/编辑），无需回基础档案。

### 库存流水（movements）
- 确认单据后生成的库存流动（采购入库、领用、调拨入/出库、盘盈/盘亏调整、作废回滚），含数量变化、结余、经手、去向、发票。

---

## 单据流程（草稿 → 确认 → 流水）

1. 先在基础档案建仓库、Item、子 Item、往来对象。
2. 「新建单据」→ 选类型/仓库/往来对象/经手对象；采购入库可选关联报销单；逐行选子 Item、数量、单价/成本、备注 → 保存为**草稿**。
3. 草稿点「**确认**」生成库存流水并更新库存；确认前可上传发票、编辑、删除。
4. 已确认单据如需回滚点「**作废**」（二次确认，回滚库存）。
5. 从报销详情「采购入库」跳入时会自动打开采购入库表单并按报销单预填。

---

## 注意事项

- 只有草稿可删。
- 只有**未被引用**的仓库、子 Item、往来对象可删；Item 需先删光子 Item。
- 库存变动一律走「单据确认」，不直接改库存。
