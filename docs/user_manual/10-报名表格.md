# 10 · 报名表格（特别活动）

**用途**：管理「特别活动/一次性活动」的报名表：创建表格、配置字段与收费、查看报名成员、记录付款、生成公开报名/付款链接。

**入口**：CRM →「报名表格」→ `/crm/register`。`?form_id=<id>` 选中表格、`?form_tab=<tab>` 切换分页。

**权限**：
- 进入工作台 = `form_read` / `form_edit` / `member_detail` 任一
- 创建/编辑表格、费用、字段 = `form_edit`
- 看成员敏感资料/家长/付款 = `member_detail` 或 `form_edit`
- 帮成员记录付款 = `form_edit` 或 `account_edit`
- 把付款标为「已确认」= `account_edit`

---

## 列表与新建

1. 进入后看到表格列表（标题、截止日期、报名人数、关联活动、收费项数、创建时间）。
2. 「新建表格」：填标题、截止日期、详情；勾选配置开关（Email、家长同意书、家长1/2、地址、医疗、过敏、其他备注）；可预设扩展字段。
3. 点表格行进入详情（6 个分页）。

## 详情分页

### A. 报名成员
- 搜索（姓名/NRIC/电话/Email/家长/表格内容）、**下载 Excel**、点成员进详情、发/看家长同意书、移除成员（`form_edit`）。
- 列：姓名、电话、性别、NRIC、**年龄（按 NRIC 计算）**、付款状态、报名时间（可排序）。
- 无 `member_detail` 权限只显示报名人数统计。

**成员详情弹窗**：
- **基本资料**（可编辑）：中英文名、NRIC、电话、Email、性别、地址、医疗、过敏、其他备注、家长1/2 及电话；扩展字段。改动累计后「保存修改」。
- **改 NRIC** 有特殊流程：先预览影响（受影响报名/付款/青少年班/家长同意书；若目标 NRIC 已存在会提示**合并**到已有成员），确认后才保存。
- **付款记录**：列出每笔付款（单号、状态、方式、金额、时间、柜台、截图可看原图）。
- **帮成员记录付款**（有权限时）：选收费项 → 选付款方式（现金/QR/CDM/银行转账/支票）→ 可上传截图 → 有 `account_edit` 可勾「直接标记为已确认」并填柜台 → 「记录付款」（成员须有 NRIC）。

### B. 报名费
- 维护收费项：类别、金额、年龄起、年龄止（可空）、说明、**付款资料图片**（即公开付款页展示的收款 QR/账户图，支持 HEIC 自动转 JPEG）。
- 顶部有付款页入口链接。

### C. 表格内容（扩展字段）
- 默认字段（中英文名、NRIC、年龄、性别、邮箱、地址、医疗、过敏）之外，添加自定义字段（label / 类型 / 选项 / 顺序）。

### D. 关联活动
- 「选择活动」关联 CRM 活动；卡片可跳转活动详情，可移除。

### E. 基本设置
- 可编辑：标题、截止日期、**最大报名人数（留空=不限）**、详情（自动防抖保存）。
- **报名状态**控件：显示状态（报名进行中 / 已手动终止 / 已过截止日期 / 名额已满）与「已报名 N / max 人」。可「**终止报名**」或「**重新开放报名**」。
- **字段开关**：启用各默认字段。

### F. 公开报名页
- 显示两条链接（**报名页** `/api/form/index/<id>`、**付款页** `/api/form/pay_register/<id>`），各有「复制链接」，并用手机外框实时预览。

---

## 公开页（访客用，无需登录）

### 报名页
访客填中英文名、NRIC、电话、性别等（视字段开关）+ 扩展字段 + 家长同意书（若启用）→ 提交。
- **报名截止判定**：手动终止 / 已过截止日 / 名额已满 任一都会显示「报名已截止」或「报名人数已满」，无法提交。

### 付款页
1. 输入 NRIC → 自动算年龄 → 列出**本表单且符合年龄**的收费项。
2. 选一项 → 查看收款二维码 → 上传付款凭证 → 提交。
3. 付款按 NRIC 关联成员（未报名/无该 NRIC 会被拒）。

---

## 注意事项

- 付款状态三态：处理中 / 已确认 / 失败；只有 `account_edit` 能确认，确认在 [收款审核](06-财务-收款审核.md) 完成。
- 报名/满员的门禁只作用于「报名」，不作用于「付款」。
