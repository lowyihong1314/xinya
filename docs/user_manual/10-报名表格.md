# 10 · 报名表格(特别活动)

给一次性活动做报名收费:建表 → 发链接 → 看名单收钱。

## 建一张报名表

1. 打开 [报名表格](#/crm/register),点**新建表格**。
2. 填标题、截止日期、活动详情;勾选要收集的资料(Email、家长同意书、地址、医疗、过敏等)。
3. 建好后点表格行进入详情,共 6 个标签页。

## 六个标签页怎么用

- **报名成员**:名单在这。可搜索、**下载 Excel**、点人看详情。成员详情里能改资料、看每笔付款、**帮成员记录付款**(现场收现金时用:选收费项和方式,可当场标记已确认)。
- **报名费**:设收费项——类别、金额、适用年龄段,**上传收款二维码图**(付款页会显示它)。
- **表格内容**:加自定义问题(文本、选项等)。
- **关联活动**:跟 [创建活动](02-创建活动.md) 里的活动连起来。
- **基本设置**:改标题/截止日/**最大人数**;要提前收摊点**终止报名**,想续办点**重新开放报名**。
- **公开报名页**:这里有**报名页**和**付款页**两条链接,点**复制链接**发到群里,旁边还有手机样式实时预览。

## 报名者看到什么

- **报名页**:按你的设置填资料提交;过了截止日、满员或你手动终止后,页面会显示「报名已截止」。
- **付款页**:输入 NRIC → 自动算年龄、显示该付的收费项 → 扫你上传的二维码付款 → 上传凭证。
- 凭证进入 [收款审核](06-财务-收款审核.md),财政确认后该成员就是「已付款」。

> 已付款(处理中或已确认)的成员**不能被移除**,防止名单和钱对不上。
