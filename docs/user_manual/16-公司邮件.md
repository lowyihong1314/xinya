# 16 · 公司邮件系统

**用途**：用 `{用户名}@utba.my` 公司邮箱**发送邮件**；变更/验证个人接收邮箱并自动配置转发。

**入口**：个人控制台（Profile）→「账户」区 → 邮件面板。

**前提**：账号必须有**用户名**才能确定发件地址（`{用户名}@utba.my`）。

---

## 操作

1. **查看已发邮件**：列出本人已发送的邮件（最多 100 条，含发件地址）。
2. **发送邮件**：填收件人、主题、正文，支持抄送（cc）/密送（bcc）。系统先记录再发送，失败会标记为 failed。
3. **更换接收邮箱**：填新邮箱 → 系统先发**验证链接** → 点了验证后才真正生效。
4. **验证现有邮箱**（老用户）：为已填但未验证的邮箱补一次验证。
5. 邮件里的验证链接**无需登录**即可点开，成功后写入邮箱并配置 Cloudflare 转发（把 `@utba.my` 收到的信转到你的真实邮箱）。验证链接 **24 小时**有效。

---

## 注意事项

- 改邮箱在**点击验证前不会变更**。
- 发件依赖第三方发信服务、转发依赖 Cloudflare，需系统预先配置好凭据。
