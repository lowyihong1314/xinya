# 16 · 公司邮件

每个有用户名的账号都有公司邮箱 **用户名@utba.my**,可以在系统里直接发信。

## 发邮件

1. 打开 [个人控制台 → 账户](https://utba.my/#/profile/account),找到邮件面板;
2. 填收件人、主题、正文(支持抄送/密送),点发送;
3. 面板下方能看到你**发过的邮件**和成功/失败状态。

## 收邮件(设置转发)

别人发到你 @utba.my 的信,会**自动转发**到你的真实邮箱。设置方法:

1. 在邮件面板填你的**接收邮箱**;
2. 系统发一封**验证邮件**过去,点里面的链接(24 小时内有效);
3. 点完就生效,以后的来信自动转过去。

> 没点验证链接之前,改动不会生效。
