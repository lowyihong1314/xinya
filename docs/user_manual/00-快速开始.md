# 00 · 快速开始

## 登录

1. 打开 [CRM 工作台](#/crm)。没登录的话会看到「请先登录后台」,点**打开登录框**。
2. 输入用户名和密码,登录后 7 天内不用重新登录。
3. 忘记密码?找管理员帮你重置。

## 认识界面

登录后,**左边是菜单**,右边是工作区:

- [用户与部门](#/crm/user_control) —— 管人、管权限、**会员管理**
- [特别活动](#/crm/event_table) —— 创建活动、报名表格
- [法会](#/crm/dharma_event) —— 盂兰盆、点灯
- [财务](#/crm/finance) —— 报销、收款审核、销售、总账
- [资产库存](#/crm/asset) —— 仓库和物品
- [长期活动](#/long_open_registration_form) —— 青少年佛学班
- [监控](#/crm/cctv) —— 摄像头直播和回放
- [唱游歌簿](#/crm/songbook)、[文件系统](#/crm/files)、[使用说明](#/crm/manual)

点菜单名字会展开子项;再点子项进入具体页面。

## 三个常用小知识

1. **把你看到的页面发给同事**:直接复制浏览器地址栏的网址发过去,对方打开就是你现在看的这一页。
2. **删除类的按钮都会再问一次**「确定吗?」,不小心点到也不怕。
3. 列表几乎都有**搜索框**和**页码**,东西找不到先搜一下。
