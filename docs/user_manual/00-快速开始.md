# 00 · 快速开始 · 登录 · 权限总览

## 登录

1. 打开系统网址后进入 `/crm`（CRM 工作台）。未登录时页面提示「请先登录后台」并弹出登录框。
2. 输入用户名与密码登录。登录状态默认记住 **7 天**。
3. 登录后左侧显示模块导航，右侧为当前模块工作区。

## CRM 工作台结构

- **左侧导航**：按模块分组（用户与部门、创建活动、法会、财务、资产库存、报名表格、长期活动表格、监控、唱游歌簿、文件系统）。部分模块下还有子项（如财务下有报销申请 / 收款审核 / 销售收入 / 总账等）。
- **URL 参数即状态**：几乎每个模块用 URL 查询参数记录当前位置，例如：
  - 财务：`/crm/finance?account_router=claim_req`
  - 法会订单详情：`/crm/dharma_event?fahui_view=ylp_order&fahui_order_id=551&fahui_ylp_version=2025_YLP`
  - 报名表格：`/crm/register?form_id=21&form_tab=members`
  - 复制 URL 即可把「当前正在看的页面」发给同事，打开后定位到同一位置。

## 权限总览

系统采用 **RBAC（基于角色/部门的权限）**：

- 权限（Permission）挂在**部门（Department）**上。
- 用户加入部门后，即拥有该部门的所有权限。
- **给某人放权 = 把他加进拥有该权限的部门**（见 [01-用户与部门](01-用户与部门.md)）。

若访问某功能时提示「没有权限」或看不到某些按钮/数据，通常是缺少对应权限。常见权限见 [README 的权限速查](README.md#权限速查)。

## 公开页（无需登录）

以下页面对外发布，访客无需登录即可使用：

| 公开页 | 用途 |
|---|---|
| 报名页 `/api/form/index/<表格ID>` | 特别活动报名 |
| 付款页 `/api/form/pay_register/<表格ID>` | 报名费付款 |
| 牌位填写页 `/#/ylp-registration` | 盂兰盆法会自助填牌位 + 付款 |
| 会员申请 / 青少年班 `/template/...` | 长期活动报名 |
| 付款凭证签名页 `/payment-voucher-sign/:token` | 收款人签名 |
| 相册首页 `/` · 活动详情 `/event/:id` | 活动照片墙 |
| 信息页 `/info` · 树洞 | 关于我们 / 历史 / 留言 |

## 通用约定

- **危险操作**（删除、取消、作废等）都会弹出**确认对话框**，需二次确认。
- 多数列表支持**搜索、筛选、分页**；部分支持**表头点击排序**与**导出 Excel / PDF**。
- 涉及**付款审核**的模块，收款状态统一为：**处理中（process）→ 已确认（checked）→ 失败（fail）**，其中「确认 = 批准」。
