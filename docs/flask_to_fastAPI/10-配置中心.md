## 2. 目标

**一个文件说明这个系统需要什么。** 所有 API 地址、Token、开关、路径，全部在
`system_config.env` 里有一行，且有一份带注释的 `system_config.example.env` 入库。

## 3. 文件布局

```
/srv/flaskapp/xinya/
  system_config.env          # 真实值，chmod 600，不入库（加进 .gitignore）
  system_config.example.env  # 键 + 注释 + 安全的默认值，入库
  core/config.py             # 唯一读取入口
```

多项目共用的值（数据库、Twilio…）仍可放 `/srv/flaskapp/system_config.shared.env`，
由 `system_config.env` 用 `EXTENDS=` 指向，加载顺序：**shared → 项目 → 进程环境变量**
（后者覆盖前者，方便临时调试和 CI）。

## 5. 读取入口 `core/config.py`

用 `pydantic-settings`（FastAPI 生态的标准做法，Flask 阶段也能用）：

```python
# core/config.py
from functools import lru_cache
from pydantic import Field
from pydantic_settings import BaseSettings, SettingsConfigDict

class Settings(BaseSettings):
    model_config = SettingsConfigDict(
        env_file=("/srv/flaskapp/system_config.shared.env", "system_config.env"),
        env_file_encoding="utf-8",
        extra="ignore",
    )

    app_name: str = "xinya"
    app_env: str = "production"
    app_debug: bool = False
    app_base_path: str = "/"
    app_public_origin: str = ""
    secret_key: str                      # 没有就启动失败，不给默认值
    db_host: str
    db_name: str
    db_user: str
    db_password: str
    redis_url: str = "redis://localhost:6379/0"
    data_root: str = "/srv/flaskapp/xinya/database"
    byteplus_api_key: str = ""
    # …按上面的 .env 逐一声明…

    @property
    def sqlalchemy_uri(self) -> str:
        return f"postgresql+psycopg://{self.db_user}:{self.db_password}@{self.db_host}/{self.db_name}"

@lru_cache
def get_settings() -> Settings:
    return Settings()

settings = get_settings()
```

好处：
- **启动即校验**。缺 `SECRET_KEY` 直接起不来，而不是跑到某个接口才炸。
- 类型转换免费（`APP_DEBUG=false` → `bool`，端口 → `int`）。
- 测试里 `get_settings.cache_clear()` + 环境变量即可替换，不用碰文件。

## 6. 前端怎么拿

前端有自己的 `VITE_*` 体系（`import.meta.env`），**不能**直接读 `system_config.env`。
做法：构建前用脚本从 `system_config.env` 生成 `frontend/.env.production`：

```bash
# scripts/gen_frontend_env.sh —— 只导出明确标记为前端可见的键
grep -E '^(VITE_|GOOGLE_MAPS_EMBED_API_KEY|APP_BASE_PATH|APP_PUBLIC_ORIGIN)=' system_config.env \
  | sed 's/^GOOGLE_MAPS_EMBED_API_KEY=/VITE_GOOGLE_MAPS_EMBED_API_KEY=/' \
  | sed 's/^APP_BASE_PATH=/VITE_BASE_PATH=/' \
  | sed 's/^APP_PUBLIC_ORIGIN=/VITE_PUBLIC_ORIGIN=/' \
  > frontend/.env.production
```

⚠️ **白名单式导出，不是黑名单**。前端 env 会被打进 JS 包、对所有人可见 ——
任何 `*_SECRET` / `*_TOKEN` / `*_PASSWORD` 泄进去就是事故。脚本里要有硬性断言：

```bash
grep -qE 'SECRET|PASSWORD|_TOKEN|AUTH' frontend/.env.production && { echo "❌ 密钥泄漏到前端 env"; exit 1; }
```

## 7. 迁移步骤（D13：直接复制，不做回落）

⚠️ `/srv/flaskapp/_token.py` 被 **6 个项目**共用（`BearBad` `devops` `fahui`
`kellytools` `sengchong` `xinya`），**绝不修改它**。本项目只把值复制出来，
从此各走各的。原计划里的"回落到旧来源"那一步**取消** —— 一次性切干净。

1. 写 `system_config.example.env`（入库）+ `core/config.py`。
2. 把 `/srv/flaskapp/_token.py` 的 17 个键、`.flaskenv` 的 10 个键的**值**
   复制进 `system_config.env`（dev 与生产各一份，chmod 600）。
3. 把代码里 20 处读配置的地方（14 处 `os.environ`/`os.getenv` +
   6 处 `from _token import`）换成 `settings.xxx`。
4. 硬编码的外部地址（BytePlus/Cloudflare/Resend/Google）换成 `settings.*_base_url`。
5. 删掉仓库里的 `_token.py`、`env_value()` 那套 `.flaskenv` 手动读取，
   同步改 `run.py`（它读 `DEBUG` / `DEBUG_PORT`）。
6. `.gitignore` 加 `system_config.env`。

> **代价**：共享值（DB 密码等）以后改动要改两处。可接受 ——
> 本项目马上迁到独立的 PG 库（[15](15-PostgreSQL迁移.md)），共享面会自然消失。
