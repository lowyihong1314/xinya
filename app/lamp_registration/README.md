# Lamp Registration

This package owns lamp registration, payment submission, receipt file storage, and payment approval APIs.

## Files
- `routes.py`: Flask routes for `/lampRegistration_API/*`.
- `services.py`: registration and payment business logic.
- `serializers.py`: registration serialization helpers.
- `storage.py`: uploaded payment proof file handling.

## Notes
- External URL prefix stays `/lampRegistration_API` for compatibility.
